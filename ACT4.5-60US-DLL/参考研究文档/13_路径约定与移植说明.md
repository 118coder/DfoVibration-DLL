# 13 路径约定与移植说明（给别人看之前先读这份）

> 这套资料里的**文件路径**是整理者本机的示例（`E:\LX\...`、`G:\game\...`），你电脑上不一样。本文给出统一解法：**文档正文用路径变量，你按对照表填自己的路径**；文末附一键生成"我的路径版本"的脚本。

---

## 一、两类"本地信息"必须先分清（最容易混淆）

| 类别 | 例子 | 换电脑 | 换客户端版本 |
|---|---|---|---|
| **机器相关**（路径/盘符/用户名/PID/日志位置） | `E:\LX\DfoVibration_OLD`、`G:\game\90US\USDOF`、`C:\Users\XXX` | **会变**，必须替换 | 不变 |
| **版本相关**（内存地址/偏移/hook 字节/函数地址） | `0x4D2C50`、`+0x1168`、hookLen=9、`E9` 改写 | **不变**（同版本通用） | **会变**，需按 `07` 重定位 |

结论：
- 文档里的 `0x……` 地址**不要因为换电脑而怀疑**——同一个客户端版本在任何电脑上都是这些地址（老版无 ASLR，新版地址也按构建固定）。
- 真正要改的是**文件系统路径**。下面给变量表。

## 二、路径变量对照表

文档正文统一使用尖括号变量；下表给出"整理者本机示例"，请把你自己的路径填进最后一列。

| 变量 | 含义 | 示例（脚本默认值） | 你填你的 |
|---|---|---|---|
| `<1.5版目录>` | 新版（90US）完整产品目录：DfoVibration.dll + SorahkDFO + 源码 + 文档 | `D:\DfoVibration\1.5版` | |
| `<OLD研究仓>` | ACT1 老客户端适配研究仓：DfoVibration_OLD.dll + Loader + 46 篇阶段报告 | `D:\DfoVibration\DfoVibration_OLD` | |
| `<V3目录>` | 宿主主程序 V3 目录：SorahkDFO-新UI版.exe + DLL源码 + 研究文档 | `D:\DfoVibration\V3` | |
| `<ACT1游戏目录>` | ACT1 老客户端安装目录（内含 DNF.exe） | `F:\A1\LMA1S-release\Client` | |
| `<90US游戏目录>` | 90US 新版客户端安装目录（内含 DFO.exe、`us_extend_dll\`） | `G:\game\90US\USDOF` | |
| `<IDA目录>` | IDA Pro 9.4 安装目录（含 `idat.exe`） | `C:\Program Files\IDA Professional 9.4` | |
| `<构建目录>` | 宿主 Rust 源码的 **纯 ASCII** 构建目录（中文路径会链接失败） | `C:\Sorahk-build` | |

## 三、三种使用方式，按需要选

### A. 只是参考阅读（最省事）
把变量在脑子里替换成自己的路径即可，不用改文件。重点看 `01`~`09`。

### B. 生成一份"我的路径版本"（推荐给别人）
用文末脚本，或手工：把本资料夹复制一份，用编辑器全局替换变量为你的路径。替换后文档里的示例就与你的机器一致，可直接当操作手册用。

### C. 你的客户端版本与文档不同（换版本适配）
地址会变，按 `07_逆向方法论与地址速查.md` 第一部分第五节「换版本适配速查」重定位：
- 先找 **P0 加密四件套**（表基指针/密钥全局变量/槽解算器/槽注册器）——拿到它一切加密字段都能读；
- 再找 P1 玩家对象与计数器、P2 hook 锚点（入口前 16 字节必须是普通指令，**绝不可 E8/E9/JMP rel32 开头**）；
- 交付格式三件套：地址 + 反汇编证据 + 一句话确认理由。
可复用的部分：hook 引擎/汇编 stub/6ms 轮询框架/共享内存协议/宿主全套/加密读法公式。

## 四、给别人时的前置条件清单

发这套资料前，确认对方具备：

| 项 | 要求 |
|---|---|
| 客户端 | 与文档对应版本：ACT1（LMA1S-release，x86）或 90US（x86）；**版本不同则地址全部作废** |

## 六、如何换成你自己的路径（手工，两分钟）

不需要任何脚本，两种做法任选：

**做法 1：编辑器全局替换**
用 VS Code / Notepad++ 打开本资料夹，选"在文件中替换"，把第二节表格里 7 个变量逐个替换成你的路径（建议先复制一份资料夹再改，保留原版）。

| 查找 | 替换为（示例） |
|---|---|
| `<1.5版目录>` | `D:\DfoVibration\1.5版` |
| `<OLD研究仓>` | `D:\DfoVibration\DfoVibration_OLD` |
| `<V3目录>` | `D:\DfoVibration\V3` |
| `<ACT1游戏目录>` | `F:\A1\LMA1S-release\Client` |
| `<90US游戏目录>` | `G:\game\90US\USDOF` |
| `<IDA目录>` | `C:\Program Files\IDA Professional 9.4` |
| `<构建目录>` | `C:\Sorahk-build` |

**做法 2：直接带着变量读**
不改文件也完全可以——把 `<90US游戏目录>` 读成"你的 90US 游戏安装目录"，`<OLD研究仓>` 读成"你的 ACT1 研究仓目录"。技术内容与路径无关。

> 本文档只讲约定，不提供脚本；有整套报告和思路的话，替换路径这种机械活按上表做即可。

## 七、注意事项

1. **别把本机路径写回原始项目**：本资料只是参考副本，原始三个目录仍按原位只读使用。
2. **日志路径同理**：文档提到的 `SorahkDFO_vib.log` / `DfoVibration_OLD_dll.log` 都在各自 exe/DLL 同目录，按变量替换理解。
3. **md5/SHA256 不用替换**：它们是构建指纹，用来确认"是不是同一份产物"，与电脑无关。
4. **PID/窗口句柄**不写进文档（每次运行都变），排障时现场看任务管理器即可。
