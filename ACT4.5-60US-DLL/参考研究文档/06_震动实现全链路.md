# 06 震动实现全链路（从游戏事件到手柄马达）

> 本文回答一个具体问题：**一个游戏内的战斗事件，是怎么变成手柄上那一下震动的？** 两版各自走什么路。
> 素材：`阶段报告/40_新旧版架构完整对比.md`、`42_通道冲突定案与合成式修复.md`、`43_SorahkDFO宿主问题总结.md`、`无损对接交接文档.md` 第六/七节、`1.5版/开发文档/00_项目总览与无损续接指南.md`、V3 `HANDOFF.md` 与 `震动系统开发规范_v20.md`。

---

## 一、五段式全链路（两版通用）

```
① 游戏内部信号        ② 采集层（DLL，游戏进程内）          ③ 传输           ④ 引擎合成（宿主）          ⑤ 输出
战斗/评分/移动/死亡 → hook 或内存轮询 → VibEvent → 共享内存环 → 参数/衰减/合成 → XInputSetState
```

- **DLL 从不调用 XInput**（两版源码全文 grep `XInputSetState` 零命中）——马达控制只在宿主。
- **DLL 从不写游戏内存**（老版硬约束：写路径破坏 TerSafe 完整性标记；新版同样只读）。
- 进程隔离：采集崩溃不连累游戏；删除 DLL 即完全还原。

## 三、事件发送节奏（宿主手感的决定性差异）

| | 新版 | 老版 |
|---|---|---|
| hook 回调 | 只 `InterlockedIncrement`（纳秒级） | 直接组装 VibEvent 入环（微秒级） |
| 发送 | collector 12ms 批量：每类一条 `count=N` | 逐条直发 `count=1` + 分级去抖（40/120/200ms）+ FONT 六子槽 |
| 宿主效果 | combo_hits 一次 +N，同类合并为一次注入 | 每事件独立走宿主注入窗（手感连续、可分级去抖） |

⚠ **v13.27 教训**：老版照抄新版"计数器+批量冲刷"被用户实测回退（"仍不适合"）——冲刷改变事件节奏与 count 语义。v13.28 恢复逐条直发。**v13.39 的折中**：hook 上下文只计数，collector 6ms **逐条拆发**（count=1 保连击语义），既降开销又保手感。
**结论：新版架构可借鉴"源的选择"，不可盲目照抄"发送节奏"。**

## 五、宿主引擎合成（事件之后发生了什么）

### 5.1 效果模式（两版共用）
- **decay**：注入即设 `left/right`，逐帧按衰减常数降。
- **hold（保持式）**：`hold_until = now+150ms`，激活期每帧强制输出 `hold_l`（用于 CC 被控平滑保持）。
- **rhythm（节拍式）**：`rhythm_until = now+120ms`，输出方波节拍（曾用于怪物 DOT）。
- **mode3（V3 新增）**：玩家 DOT 红字 → 衰减脉冲（每红字一震，不再无缝续期）。
- **mode4（V3 新增）**：怪物 DOT 0x04 → 90ms 衰减脉冲。

### 5.2 合成式输出（v13.34 + v13.37 两层修复）
- **引擎层**：hold / rhythm / decay 三分量独立推进，`update` 尾部取 `max` 合成；`inject` 三兄弟不再互相清零。修「命中打断持续震」「持续震盖掉命中」。
- **主循环输出层**（v13.37，最深一层）：`XInputSetState` 原本是**三选一互斥**（评分脉冲激活期 > 移动中 > 普通引擎输出）——**走位时所有战斗震动被移动步伐覆盖**。修复 = 评分/移动分支各自合入 `engine.finalize` 输出（含平滑+motor+随机增益）取 max。这一层解释了全部历史谜团：打霸体（站桩）每刀必震、近战走位"命中不震"、神枪手站桩从未暴露。

### 5.3 量纲与死区（v13.30 / v13.27 / v13.36）
- **FONT 注入链补 `/100`**：此前 FONT 以 0-100 原值灌入，finalize `.min(1.0)` 钳位 → 受击/命中/暴击全部饱和满幅、滑块无梯度、强度上限失效。修复 = `s_out /= 100.0` + Burst 保底同步归一。
- **重映射前置 + 死区只杀真零 + 迟滞退出线=阈值**（v13.27 补丁）。
- **硬约束**：`remap_min ≥ 死区阈值`（v13.36 曾把 remap_min 降到 20 而死区还 28 → 20-28% 全被吞 → 同步把死区降到 15）。
- **梯度恢复**：输出曲线 95→100（线性），修复"滑块 25→31.8% vs 100→42%"的压扁。

### 5.4 手感算法清单（宿主 `vibration.rs`）
连击 `combo_hits`（1500ms 清零，is_attack 事件累加，`combo_mul` 乘所有输出）；密度自适应（窗口命中超阈值降强度）；输出平滑（一阶低通）；随机增益（**默认 0=关闭**，个别职业预设才设 ±18%）；马达分工（Xbox360 风格）；移动正弦走路质感（步频 380ms/着地脉冲/相位交替/平滑/低阈值抑制，params[23-28]）；评分动态衰减（类鬼泣：攻击 +1.0 / 受击命中 +0.5，上限 8，停手 2000ms 后 2 级/秒衰减，倍率 60%~120%）；节流窗口；**职业专属算法 algo_id（实际 1~57，每转职一个，按 13 组行为 A-M 分派——旧写"1-15"源自过时注释，详见 `08` §5）**。

### 5.5 宿主门槛链与手感定量（报告 30/33 补录）

- **真 enabled 总闸**：`config.rs L71-72` → `state.rs L694` AtomicBool → `vibration.rs L1323` `enabled && !is_paused()`；GUI 两处按钮只翻转原子量、**不落盘**；隐藏暂停门 `switch_key` → `toggle_paused()`。
- **门控 G0-G14 定量**：G4 注入间隔 `P_FONT_IVL=40ms`；G5 节流窗=0（禁用）；G6 受击 `P17=30`/特殊 `P13=80`；G7 反击增幅 `P55=150%`；G9 `P_ATTACK/P_MAX/P_MASTER=100/55/100`；G10 死区 28%（迟滞 1.8×）；G12 `split<40%` 只留主导马达；G13 输出 ×随机（**默认 `random_gain=0`=关闭**，个别职业预设才 ±18%）×平滑 55%。
- **受击 vs 命中波形定量**：峰值完全相同（100%）、衰减常数完全相同（25/20ms）、总嗡鸣差仅 **24-27ms** → 人手不可分辨，这才是"受击和伤害数字绑在一起"的定量本质；特殊/暴击总时长 191~264ms ≈ 2.5~3.2 倍。公式：`t_sat=dec×ln(s_out×lr×base)`、`t_dead=dec×ln(s_out×lr×base/0.2618)`。
- **G4 40ms 互吞量化**：P(受击被吞)≈3.7% / 峰值 7.3% / 爆发 28%；主因排序 **波形等价 > 掩蔽 > 反击增幅 > G4**。补丁 A 分通道窗 `last_font_ch[4]`（0=受击/1=特殊/2=DOT族/3=命中）；补丁 C 受击签名：衰减 25→45~50、受击 R 权重 −40~−60、强度 30→40。
- 受击后 600ms 内命中被反击增幅 **×1.5** → 互殴期"命中底震"反而比受击更长更重。
- **震感弱六层叠乘**：槽16=25、槽51=25、槽29=40/500ms(−35%)、槽4=55%、槽35=25ms、split_thr=40% → 常态单发命中 ≈6-12%，仅 remap 保底 28% 抬到 31-34%。
- **0x10 耦合 `combo_hits`**：`is_attack` 含 `FONT_SPECIAL` → `combo_hits += count` → `combo_mul=(1+hits/100×30/100×0.6).min(1.6)` 抬高**所有后续震动**；暴击高频可触发密度自适应（40 hits/500ms → 强度 ×0.65、注入间隔 ×2）反而削弱命中/受击；**受击 0x02 无耦合**；`VEV_COMBO` 每发 +10 连击。
- **蓝牙根因**：XInput 轮询 1ms（4000 次/s）干扰蓝牙握手 → 降到 5ms。
- **移动/手感基线**（1.5 研究合集）：L:R = 命中 5:3/45ms、特殊 9:8/70ms、受击 8:2/35ms、DOT 25:15/150ms hold、装备 4:6/120ms rhythm 90ms 方波、状态 6:4/110ms；状态机条件：连击里程碑 50/100/200/400、爆发 250ms 内 ≥6 命中、受击反击 600ms×1.5、唤醒 3s、连击中断 >30、DOT 3% 微震。
- 震屏实测（v13.28）：全日志 52 次 `[shake]`，degree 分布 2×19 / 3×9 / 5×24。

### 5.6 新版 DOT 分类优先级链（报告 38）

`vib_dispatch_common_hit` 主分类为 **elif 链 `0x20 > 0x10 > 0x08 > 0x04 > 0x01 > 0x02`**；a6 含 0x20 → `g_cnt_hp++`；collector 12ms flush → `count=N` 打包 `VEV_FONT 0x20`。
新版 DOT 四事实：① 纯飘字驱动、无状态轮询；② 无 HP 观测（血之狂暴结构不可见）；③ **无归属过滤**（毒怪也震 0x20）；④ 频率 = 红字 500ms 节流 + 12ms 批量。

**S1 高级算法实现顺序**（此前文档只有名词）：
- 群怪聚合记账（`:232-240 / :1181-1205 / :1339-1348 / :1627-1662`）：窗内按通道记能量 `font_carry_s[ch]`、L/R `font_carry_lr[ch]`、末笔模式 `font_carry_mode[ch]`、到期戳 `font_carry_until[ch]`；下一发 `s_out=min(s_out+carry, merge_cap×density_scale)`；tick 到期无后续注入则补发收尾脉冲（门槛 `FONT_CARRY_FLUSH_MIN=0.06`，补发必须刷新 `tail_peak`，否则被脉冲落地误杀）。
- 命中限频（`:1208-1241`）：只对 ch=3；超额命中**全额记账**（不推进 IVL 锚点，防通道饥饿），下一发兑现变厚；`hitcap_max=0` 关闭。
- 命中聚合窗 `hitmerge_ms`（`:1171-1173`，默认 60ms）：ch=3 专属更宽窗，群怪一刀多条命中合并成一震。
- 持续压制（`:1349-1366`）：长窗统计真实注入数达到"限速上限×秒数"后，命中再降 `sustain_reduce`%（默认 3 秒/30%）。
- 脉冲落地（`:1708-1723`）：密度激活或限频咬合时，衰减尾巴低于峰值 `tail_land_pct`% 即归零。
- 命中风暴抽样（`:1071-1131`）：只统计/丢弃"纯命中"（0x01 且不含受击/DOT/状态/特效/特殊）；窗内达 `storm_thr`（默认 10）进入风暴，确定性抽样每 `stride=100/keep` 条留 1 条；丢弃事件不打 IVL 锚点/不进记账/不占限频；停手超 `storm_pause_ms`（400）立即恢复。风暴期可静音评分族与怪物异常（`:858-873 / :1016-1028` 两开关）。
- S1 计数口径（`:2232-2243`）：只有 `last_injected && etype!=VEV_MOVE` 才计入 `vibration_events_received`；S4 全量。

**其他机制补录**：
- 走位能量 `move_charge`（`:1549-1555 / :1374-1382`）：移动中按 p[21]%/秒积累（上限 1.0），停手后 4s 线性流失；停手窗口 p[39] 内下一次攻击 ×(1+charge×p[22]/100)。
- 唤醒/里程碑/连击中断脉冲（`:963-978 / :1561-1572`）：进入战斗首击（或 >5s 无事件）发 p[56]；跨 50/100/200/400 发 p[57]；连击超 p[49] 门槛且 p[45] 窗口内无连击发 p[58]。
- 评分衰减 ghost（`:1002-1006 / :1606-1617`）：攻击 +1.0、受击/命中 +0.5，上限 8；停手超 2000ms 后按 2 级/秒衰减；倍率 = `min+grade/8×(max-min)`，默认 60%~120%。
- **三档波形基线**（醒后实测清单 v13.19）：平砍 ~74ms 右手 / 被怪打 ~200ms 左手重锤 / 暴击 ~238ms+ 双手。
- ERM 大马达转子声修复（预设 v21）：轻反馈只切小马达（右，高频声小）、重击才双马达；死区 28%→**45%**、引擎衰减 clamp 30→50ms（属后续档位，与本资料 §5.3 的 28% 是不同版本，勿混）。

## 六、V3 双路线（同一引擎，两套语义）

| 环节 | S4+（新方案，默认） | S1（老方案，ACT1） |
