# 09 术语表

> 按拼音/字母混排；「出处」注明该词主要出现在哪个体系的文档里。

| 术语 | 解释 | 出处 |
|---|---|---|
| **ACT1** | DNF 老客户端代号（LMA1S-release，2008-06-17 构建），本项目「老版体系」的目标 | 老版 |
| **90US** | 新版 DFO 客户端代号（美服系，32 位无壳），「新版体系」的目标 | 新版 |
| **LMA1S-release** | ACT1 客户端版本名（安装目录见 `<ACT1游戏目录>`） | 老版 |
| **Themida** | 商业壳；老版 exe 的 `.vmp0`/`.SCY` 段即其产物 | 老版 |

| **TerSafe** | 腾讯反作弊组件（加载器 `sub_8C70A0` 强制加载 CWD 下 TerSafe.dll）；老版写游戏内存会破坏其完整性标记 | 老版 |
| **BugTrap** | 崩溃上报库（老版 WinMain 里初始化，上报到 dfighter.net） | 老版 |

| **DfoVibrationLoaded** | 新版 DLL 导出，官方启动器挂载后调用（幂等） | 新版 |
| **VibPluginLoaded / VibPluginDeinit** | DLL 导出，供注入器/宿主调用（加载/卸载契约）；两版都有 | 两版 |
| **inline hook** | 在目标函数头部改写指令跳到自己的代码（本项目用 E9 rel32 + trampoline） | 两版 |
| **stub（汇编桩）** | `hooks_asm.s` 里的汇编小段：保存现场 → 调 C 分发 → 还原 → 跳 trampoline | 两版 |
| **trampoline** | 被覆盖的原指令副本 + 跳回原函数剩余部分的跳板页 | 两版 |
| **hookLen / 变长 hook** | 覆盖的字节数；必须落在完整指令边界（`insn_len`/`calc_hook_len` 计算） | 两版 |
| **E9 rel32** | 5 字节相对跳转指令（hook 改写用）；**E8/E9/JMP rel32 开头的函数绝对不可 hook**（相对位移不重算会跳飞） | 两版 |
| **IAT hook** | 改写导入地址表指针（新版 TextOutW 采集用，已证伪） | 新版 |
| **AOB** | Array of Bytes，Cheat Engine 特征码扫描定位指令 | 两版 |
| **CE 锚点** | CE 扫到的地址/特征码，作为 IDA 反查的起点 | 两版 |
| **a5 / a6** | 伤害数字生成函数 `sub_470ED0`(老版)/`sub_E010E0`(新版) 的类型标志参数（命中/受击/暴击/DOT…） | 两版 |
| **VEV_*** | 共享内存事件类型枚举（0-25），DLL 与宿主同步 | 两版 |
| **VEVO_*** | 老版扩展事件枚举（26-36，已废弃不用） | 老版 |
| **VibShm / VibRing** | 共享内存头 / 256KB 环形缓冲结构 | 两版 |
| **Local\DfoVibrationShm** | 共享内存名（magic `0x564F4656`，version 2） | 两版 |
| **CAS 环形缓冲** | head 用 `InterlockedCompareExchange` 推进的多写者安全环；满则丢弃 | 两版 |
| **加密双表** | 老版字段加密体系：明文 = 存储值 ^ 运行时密钥 ^ (表A+4*idx)；表 A/B 镜像冗余 | 老版 |
| **运行时密钥** | `*(0x00CFD45C)` = `0xA1B2C3D4 ^ ((rand()<<16)|rand())`，每次启动随机；把地址当立即数是 v13.18 事故根因 | 老版 |
| **完整性校验** | `(密钥 ^ 槽[0]) - 槽地址 == 槽[1]`；不过则丢弃本轮 | 老版 |
| **GetHP thunk** | 游戏自身读血函数 `0x652A20: add ecx,1168h; jmp sub_402030`——HP 槽定位的黄金标准 | 老版 |
| **槽描述符** | 加密字段的 `{完整性标记, 表下标}` 结构（老版） | 老版 |
| **DecodeAdr** | 新版加密解码：二级查表 XOR（表基 `0x42D43E0`） | 新版 |
| **B5ED28** | 老版「本地玩家被击次数」计数器（受击震动主源，双重门控） | 老版 |
| **B75A14 / B75A18** | 老版玩家对象指针（副本 / 城镇），坐标 `+0x13C/0x140` | 老版 |
| **CNFrenzy** | 老版血之狂暴 buff 对象（`player+0x2A14`），直写 HP 槽 → 三路震动源都碰不到（结构免疫） | 老版 |
| **ActiveStatus** | 老版异常状态体系（类型码 1=冰冻 3=眩晕 7=石化 8=睡眠），CC 震动的正确信号源 | 老版 |
| **CC** | Crowd Control，被控制状态（冰冻/眩晕/石化/睡眠） | 老版 |
| **DOT** | Damage Over Time，持续伤害（中毒/燃烧/出血） | 两版 |
| **飘字咽喉** | 伤害数字创建的唯一入口（老版 `sub_470ED0`，新版 `sub_E010E0`） | 两版 |
| **聚合冲刷 / 批量冲刷** | hook 只计数、collector 批量发事件（新版 12ms count=N；老版 v13.39 6ms 逐条 count=1） | 两版 |
| **去抖子槽** | 老版 FONT 按 a6 标志分到独立去抖槽（48-53），防通道互吞 | 老版 |
