## ⚠ 先澄清一个最容易混淆的命名

这套项目里「新 / 老」有两个不同维度，混用会看不懂文档：

| 维度 | 老 | 新 |
|---|---|---|
| **游戏客户端** | ACT1（2008 年 LMA1S-release 私服端，Themida+TerSafe 双加密） | 90US（新版 DFO 美服系，32 位，无壳直改） |
| **宿主软件世代** | SorahkDFO v1.5/v1.6（顶栏三页签 UI，随 1.5 版交付） | DfoVibration-V3（「新UI版」，侧边栏设计系统 + S1/S4 双震动路线） |

三个原始目录分别对应：

| 目录 | 是什么 | 服务对象 |
|---|---|---|
| `【90US】...DfoVibration 1.5版` | **1.5 版完整产品**（采集 DLL + SorahkDFO 宿主 v1.5/1.6 + 全套源码/文档） | 90US 新客户端 |
| `<OLD研究仓>` | **ACT1 适配研究仓**（自研 `DfoVibration_OLD.dll` + Loader 注入器 + 46 篇阶段报告） | ACT1 老客户端 |
| `DfoVibration V3版本` | **宿主主程序新一代（V3）**：新 UI + 稳定性重构 + S1/S4 双震动路线；其 `DLL源码\` 与 1.5 版**逐字节相同** | 双端通吃（协议一致） |

**一句话总架构（两版通用）**：游戏进程内的采集 DLL（只读 hook + 内存轮询）→ 命名共享内存 `Local\DfoVibrationShm` 环形队列 → 宿主 SorahkDFO/V3（Rust）震动引擎合成 → `XInputSetState` 驱动手柄马达。游戏本体一个字节不改。
