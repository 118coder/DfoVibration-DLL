# 08 配置文件说明

> 四个配置文件的职责、关键字段与坑。字段名以 V3 运行时目录（`<V3目录>`）的实际文件为准；1.5 版同名文件字段大体一致（差异注明）。路径变量说明见 `13_路径约定与移植说明.md`。
> 权威来源：V3 `docs/震动系统开发规范_v20.md`、`docs/HANDOFF.md`、`stage.rs/config.rs` 与 DLL 源码 `common/vib_protocol.h`。

---

## 一、四文件分工

| 文件 | 归属 | 内容 | 谁写 |
|---|---|---|---|
| `DfoVibration.ini` | **DLL 侧**（游戏目录 `us_extend_dll\`） | 极简开关：`[Main] Enabled=1 / AutoStartExe=0` | 用户手改 |
| `Config.toml` | 宿主（程序目录） | 连发映射 + 程序设置 + 白名单 + 设备基线 + 版本/路线开关 | 宿主 GUI（手工模板序列化） |
| `Vibration.toml` | 宿主 | 震动参数 + 预设（`[vibration]` + `[[vibration_presets]]`） | 宿主 GUI（serde 全量落盘） |
| `JobVibration.toml` | 宿主 | 全职业预设**当前快照**（`base_job/class_name/applied/params`） | 宿主 GUI 应用职业后生成 |

铁律：**震动保存走 Vibration.toml，连发走 Config.toml**；加载顺序 `load_or_create → load_vibration_from_file → AppState::new`。

## 二、DfoVibration.ini（DLL 侧）

```ini
[Main]
Enabled=1        ; 0=不装 hook（DLL 仍驻留）；worker 每 500ms 热加载
AutoStartExe=0   ; 1=自动拉起同目录/上级目录的控制面板 exe
```
新版 DLL 会按**自身文件名**派生 ini 与日志名（`DfoVibration-V.dll → DfoVibration-V.ini/.log`），支持多版本共存。老版 DLL 零 ini（`g_iniPath` 从未赋值，ini 读取恒不执行）。

**`item_lr[26]` = 13 项 × L/R**：0 总闸 / 1 攻击频率 / 2 强度上限 / 3 衰减 / 4 连击 / 5 节奏 / 6 通用飘字 / 7 DOT / 8 特效 / 9 状态 / 10 特殊 / 11 命中 / 12 受击。**`item_lr[0]/[1]` 同时充当全局左右闸**（`gate_lr_l = 1 + item_lr[0]/100`）。六类硬编码基准 `BASE_LR`（`vibration.rs:104-111`）：DOT 0.25/0.50、特殊 0.45/0.85、受击 0.80/0.25、命中 0.35/0.70、特效 0.30/0.70、状态 0.60/0.50；滑块只在此基础上 ±100% 调制（clamp 0..2 倍）。

**`rank_lr[30]` / `rank_type_gain[15]` = 15 评分事件 × L/R**：0 评分点 / 1 闪避 / 2 暴击 / 3 破招 / 4 背击 / 5 最终击杀 / 6 凌空 / 7 命中第一击 / 8 增益叠加 / 9 释放技能 / 10 镜头震动 / 11 移动 / 12 技能震动 / 13 暴击特写 / 14 怪物死亡。
⚠ `rank_type_strength()` 当前实现**恒返回 1.0**（测试模式），故细分事件实际强度 = `rank_gain[idx]`。

**11 个高级算法总开关**（`apply_algo_toggle_params`，`vibration.rs:1945-1993`）：关闭某算法 = 把对应参数写成中性值（密度 29→100、自适应 51→0、走位 21→0、衰减组 35-38→25/55/25/60、窗口组 40-46→150/90/250/20/600/1500/3000、静默脉冲 54-58→0/100/0/0/0），滑块值保留。**`advanced_enabled` 只是 UI 展开开关，与这 11 个语义开关不是一回事。**

**其他关键默认值**：连击里程碑固定档 **50/100/200/400**；`merge_keep/cap/hold` 默认 80/100/80；`hitcap_max/win_ms` 默认 6/1000；`hitmerge_ms` 默认 60；`tail_land_pct` 默认 25；`out_smooth` 默认 55；捕获模式枚举 `DiagonalPriority / MostSustained / LastStable`。

### 4.2 `[[vibration_presets]]` 预设结构

```toml
[[vibration_presets]]
name = "默认"
params = [ ... 60 个 ... ]
item_lr = [ ... 26 ... ]
rank_lr = [ ... 30 ... ]
rank_type_gain = [ ... 15 ... ]
rank_level_gain = 100
rank_duration = 300
```
内置预设：默认 / 低频攻击职业 / 高频攻击职业 / 高振幅 / 节奏律动 / 极简轻巧 / 实战竞技 / 测试版(全0)（**V3 另有「ACT1 特供」**，仅 S1 路线可见，位置固定在「默认」之下）。
预设保存/应用/新建/还原默认 **4 处逻辑必须同步**；新增预设参数要同步「结构体 + serde helper + save/load + 4 处逻辑」。

### 4.3 补码存储规范（v20.4，必守）
- 负权重用**补码**存 u32：写 `(l as i32) as u32`，读 `load() as i32`；
- **禁止** `l as u32`（f32→u32 对负数饱和为 0，-15 变 0）；
- 源码用 `const fn lr(w: i32) -> u32 { w as u32 }`，UI 里写 `lr(-10)`，不许手写补码数字。

### 4.4 调参参考与排障开关（覆盖审计补录）

- **六类飘字建议强度区间**（1.5 研究合集）：DOT 20-40 / 装备特效 40-60 / 状态 30-50 / 特殊攻击 60-80 / 命中 20-40 / 受击 50-70。
- **排障开关**：`rank_level_gain=0`（评分等级强度 0% → 评级静音，GUI 拉高即震）；`advanced_enabled=false`（高级区展开）；GUI 的「震动:开/关」只翻转内存原子量、**不落盘**（重启恢复）；**60 参数槽启动不读 toml、总是套内置默认预设**（⚠ 位置已按源码修正：V3 前移到 **`AppState::new`（`state.rs:741-837`）**，pristine 判据 `master==0 && attack==0`；旧的 `main_window.rs L896-927` INIT_DONE 已不再是该逻辑）——真实参数在内置预设 + `JobVibration.toml`，这是"滑块调了不生效/重启被重置"的头号原因。
- **约束**：`remap_min ≥ out_threshold`（否则重映射区间被死区吞掉）；`abs_freq_enabled` 实际已退役（应用职业预设时强制关闭）。

## 七、分享 / 迁移 / 排障

- **分享**：`Config.toml`（连发映射/预设）+ `Vibration.toml`（震动参数/自建预设）直接发给对方即可，serde 全量落盘无隐藏丢失；职业微调在 `JobVibration.toml`。
- **手改 TOML 的坑**（HANDOFF 实测）：① 裸 `append` 会把键追加到多行数组括号内 → "wanted string or table" 解析失败；② 同名键插两次 → duplicate key 宿主起不来。**正确姿势 = 锚点插入法**（插在已知平键行如 `guide_seen = ` 之后），改完 `grep -c` 查重。
- **参数持久化陷阱**（v1.6 补丁 B 已修）：旧版启动无条件套内置默认预设 → 用户滑块改动重启即丢；现改为启动回灌 `Vibration.toml`（`master_gain != 0` 判据）。
- **强度三闸**：`attack_gain`（全局总闸）/`max_strength`（强度上限）/`master_gain`（全局总调整）任一为 0 → 全部震动关闭；「攻击频率」文案写"命中反馈总闸"是误导。
