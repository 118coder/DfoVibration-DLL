## 二、技术性遗漏清单

> 格式 `[文件:行号] 内容 ｜ 建议补进哪份`。共 **5 条**（其中 §二.1/§二.2 为可直接补录的实质项，§二.3/§二.4 为会话存档独有项，§二.5 为低价值备选）。

1. **[`06_子代理工作规则.md:10-21`] IDA 9.4 / IDAPython API 踩坑清单（基线全库零收录）**
   - `idaapi.get_inf_structure()` **不存在** → 改用 `ida_ida.inf_get_min_ea()` 等；
   - `ida_loader.get_imagebase` 不存在 → 用 `min_ea` 判断；
   - `idautils.Entries()` 在 9.x 返回 **4 元组**（ea, name, ordn, extra?）→ `tuple(t)` 兼容解包；
   - `ida_imp` 模块不存在（导入表 API 已改名）→ 尽量用 `idautils.Entries()` 枚举；
   - 字符串/交叉引用/取字节/段信息的正确 API（`idautils.Strings()`、`idautils.XrefsTo(ea)`、`ida_bytes.get_bytes/get_wide_dword`、`idautils.Segments()+ida_segment.getseg_name`）；
   - 脚本结尾必须 `idc.qexit(0)`，-A 自动模式下不调 SaveBase 才不写回主库；`ida_hexrays.decompile(ea)` 对 VMProtect 区会抛异常，须 try/except。
   - ｜**建议补进 `07_逆向方法论与地址速查.md` §一（工具链）**，作为「IDA 9.4 API 变更」注记。

2. **[`醒后实测清单_v13.19.md:18-20`] 受击分离手感基线（三档波形 ms）**
   - 平砍命中 = 右手短促一震 **~74ms**；被怪打 = **左手一侧、明显更长的重锤 ~200ms**；暴击 = 双手长震 **~238ms+**。
